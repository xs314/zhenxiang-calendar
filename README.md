# 真香挂历 · 待办清单

> 活动标签：`真香` `待办清单` `奶奶家的挂历风`
> 一个"无聊的功能 + 疯狂的皮肤"的单文件 HTML Demo。

把「待办清单」装进奶奶家的老式撕页挂历里：立 flag 不算数，盖上"真香"大印章才算完成。

## 运行方式

零依赖，无需构建。直接双击 `zhenxiang-calendar-todo.html` 用浏览器打开即可。

也可以本地起个静态服务（可选）：

```bash
python -m http.server 8080
# 访问 http://localhost:8080/zhenxiang-calendar-todo.html
```

## 玩法 / 演示流程

1. 页面上预置了几条经典 flag（今晚一定早睡、明天开始减肥……），每条都带期限（今晚 / 明天 / 这周）
2. 点击任意一条 → 盖上红色「真香」印章，全屏弹出"真香！"，划线作废
3. 到了期限还没做的 flag，打开页面时挂历替你自动盖「真香」章，并提示"到期真香"
4. 中间「真香档案」实时统计：累计真香、连续真香天数、嘴硬指数（立过的 flag 里最后真香的比例）
5. 右上角计数器「本页真香 × N」统计当前页
6. 全部完成后，点底部「撕页 · 清除已真香」→ 已完成条目撕页掉落，翻开新一页
7. 底部输入框可以现场立新 flag，并选「今晚 / 明天 / 这周」
8. 点「存小票」→ 导出 1080×1440 的「真香小票」PNG，可直接发群/发朋友圈
9. 演示前想恢复初始状态 → 点页脚「重置demo」，或直接打开 `zhenxiang-calendar-todo.html?fresh`

## 细节彩蛋

- 墙面挂绳 + 钉子、撕过的毛边、相邻页码残影，还原真实撕页挂历
- 宜/忌黄历按当天日期固定轮换（宜立flag / 忌食言 等）
- 页码是真实的一年第几天（如 10 月 24 日 = 第 297 页）
- 数据存 localStorage，刷新不丢

## 技术说明

- 纯 HTML + CSS + 原生 JS，单文件约 16KB
- 字体走 Google Fonts（马善政体/思源宋体），离线自动回退楷体/宋体，不影响使用
- 无任何框架与构建工具
